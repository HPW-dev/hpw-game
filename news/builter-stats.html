Статистика

На создание сборщика мечты ушло 29 дней. Благодаря плану, тестам и гугловской нейронке, я смог написать 1777 питоновских строк. Для примера, система сборки SConscript набрала 106570 строк на питоне за 20 лет разработки. Мой сборщик делает всё что нужно и он уже готов.

Предыдущие безуспешные попытки создать сборщик заняли вечность, но новый сборщик потребовал 44 часа на всю разработку - это я посчитал из инфы git-комитов.

см. bash-скрипт для подсчёта времени разработки 

#!/bin/bash
git log --author="HPW-Dev" --pretty=format:"%at" | awk '
BEGIN { total_sec = 0; limit = 7200; commit_cost = 1800; prev = 0 }
{
    if (prev != 0) {
        diff = prev - $1
        if (diff > 0 && diff < limit) {
            total_sec += diff
        } else {
            total_sec += commit_cost
        }
    }
    prev = $1
}
END { print "Примерно затрачено часов:", total_sec / 3600 }'
