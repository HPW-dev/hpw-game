Сборки H.P.W

Здесь можно скачать готовые файлы для игры. Есть версии для Windows/Linux, а так же древние мини-игры с Масюней из ВК.

>> СКАЧАТЬ ИГРУ <<

Для запуска: вытащите папку из архива и запустите bin\HPW.exe
Для открытия .7z-архива: используйте проги типа 7zip.

    Если скачать не получилось, попробуйте отсюда:

  • github.com/HPW-dev/HPW-Demo/releases
  • gitflic.ru/project/hpw-dev/hpw-demo/release
